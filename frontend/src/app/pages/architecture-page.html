Why domain API contracts?

Customers care about feeders, substations, geometry, hosting capacity, queue availability, and history. They should not pass ArcGIS query parameters or parse raw attributes.

Why immutable snapshots?

The upstream FeatureServer represents current state. When Con Edison refreshes it, older values disappear. Local snapshots preserve what was seen at each successful capture.

Where OSM fits

The hosting capacity source has feeder geometry and substation relationships, but not reliable physical substation geometry. OpenStreetMap can enrich that gap with confidence scoring.

Queue limitation

The source does not expose enough project queue data to calculate counts safely. The API returns a stable unavailable response instead of inventing a number.

Demo vs live
Demo mode

Deterministic fixture data, fast startup, repeatable history examples, and OSM enrichment proof.

Live mode

Uses the configured Con Edison ArcGIS FeatureServer and optional OSM Overpass enrichment. Larger and slower, but real.
